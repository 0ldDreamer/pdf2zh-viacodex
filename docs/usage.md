# 使用说明

本文介绍 Windows 图形界面的安装与操作。首次使用按“安装 → 登录 → 选择论文 → 开始翻译”的顺序进行；以后可直接打开 `翻译PDF.cmd`。

## 1. 安装与打开

安装前准备：

- Windows 10/11。
- 已安装 Python **3.11 或 3.12**，包含 Tcl/Tk 组件。工具不会自动下载安装 Python。
- 可访问依赖下载站点和 OpenAI 的网络，以及具有 Codex 使用权限的 ChatGPT 账号。
- 已安装官方 Codex CLI 或 Codex 桌面应用。如果没有，先安装 Node.js LTS，安装脚本会下载官方 CLI。

把源码解压到可写的文件夹，双击 **`安装依赖.cmd`**。看到 `SETUP PASS` 表示安装和自检完成；如果显示失败提示，请先处理上方错误再重试。

安装完成后，双击 **`翻译PDF.cmd`** 打开界面。翻译期间需要联网，无需打开 ChatGPT 或 Codex 桌面应用。

| 入口 | 用途 |
| --- | --- |
| `安装依赖.cmd` | 创建 Python 环境、安装依赖并运行自检 |
| `登录ChatGPT.cmd` | 单独打开浏览器进行 ChatGPT 授权 |
| `翻译PDF.cmd` | 打开翻译界面 |
| `检查环境.cmd` | 检查依赖、Codex CLI、缓存隔离与登录状态 |

首次安装依赖，以及首次翻译时下载版面模型、字体，可能需要一些时间。安装与翻译所需文件保存在项目目录内，具体位置见下文“本机数据”。

## 2. 登录与切换账号

1. 点击右上角 **登录 ChatGPT**，或双击 `登录ChatGPT.cmd`。
2. 在打开的浏览器网页中完成登录和授权。如果浏览器没有自动打开，复制运行日志中的授权链接到浏览器。
3. 回到工具，等待日志提示登录成功。右上角显示 **已登录**，按钮变为 **切换账号**；界面会自动刷新模型列表。

已有登录通常可以直接使用，不必每次重新授权。右上角标记根据本机保存的登录信息显示；如果会话失效，翻译时的登录验证可能仍会失败，需要重新授权。

点击 **切换账号** 会打开新的授权流程。新账号授权成功后才替换当前账号；取消、超时或授权失败时，原账号保留。

授权等待期间，按钮变为 **取消登录**，“刷新模型”和“开始／继续翻译”暂时禁用。关闭网页不会自动结束等待：不继续登录时，请点击“取消登录”。未完成授权满 **5 分钟**会自动超时，之后恢复界面操作。

## 3. 选择论文与保存位置

点击 **选择 PDF…**，选择要翻译的英文论文。工具会记住上次选中文献的文件夹，重启后也会保留；取消文件选择不会更新记录。如果记录的文件夹已不存在，则使用当前 PDF 所在文件夹或项目目录。

点击 **浏览文件夹…** 设置译文保存位置，默认为项目的 `outputs/`。每次开始或继续翻译都会在保存位置内新建一个任务文件夹，最终 PDF 位于该文件夹中，原始论文不会覆盖。

## 4. 设置翻译选项

### 模型与思考强度

模型列表从官方获取，实际可用项取决于账号。打开界面后等待列表加载，选择模型，再从对应下拉菜单选择思考强度。不同模型支持的强度可能不同；切换模型后，请确认强度仍符合你的选择。

“刷新模型”用于重新获取列表。查询失败时会尝试使用最近保存的官方列表，并显示缓存提示；如果没有可用列表，应先完成登录或解决网络问题。翻译运行期间不能更换模型和强度，需要先停止任务。

### 页码与行号

| 选项 | 如何使用 |
| --- | --- |
| 仅翻译指定页码 | 勾选后填写原 PDF 的页面序号，从 1 开始；不勾选则翻译全文 |
| 清理论文中的行号（无行号时不用勾选） | 论文边栏有连续行号时可勾选；只处理副本，中英对照版右侧仍为原文 |

页码按 **PDF 阅读器中的页面位置**填写，不是论文印在页脚上的页码。例如，PDF 第一页印着“125”，在这里仍填写 `1`。

| 填写示例 | 翻译范围 |
| --- | --- |
| `1-3` | 原 PDF 第 1 至第 3 页 |
| `1,3,5-7` | 原 PDF 第 1、3、5、6、7 页 |

行号清理采用保守规则，无法保证识别所有版式。翻译后应检查正文、公式和数值是否完整。

### 生成文件与其他选项

| 勾选方式 | 生成结果 |
| --- | --- |
| 只勾选“纯中文 PDF” | 生成中文版 PDF |
| 只勾选“中英对照 PDF” | 生成左侧中文、右侧原文的对照 PDF |
| 两项都勾选 | 生成两份 PDF，共用一次翻译结果 |

至少勾选一种输出版本。首次使用默认生成纯中文 PDF。

- **完成后打开 PDF**：翻译完成后自动打开结果；同时生成两种版本时，自动打开纯中文版，对照版可从输出文件夹打开。
- **记住这些设置**：保存页码、行号清理、输出版本、保存位置和自动打开选项。上次选择文献的文件夹会单独记住，不依赖此选项。

## 5. 开始翻译与查看日志

确认选项后点击 **开始翻译**。任务会依次准备引擎、解析 PDF、翻译段落和生成文件。初始化阶段可能没有段落计数，日志会先显示解析等待提示。

例如：

```text
翻译配置：模型：gpt-6.1-sol；思考强度：low；每批最多 12 段，最多 8 批并行。
翻译进度：正在初始化翻译引擎并解析 PDF，请稍候。首次运行可能需要下载版面模型或字体，此阶段可能耗时较长。
翻译进度：段落处理 16/27，新增译文 12 段，缓存 1 段，并行 2 批。
```

以上模型名称仅作示例，含义如下：

| 日志信息 | 含义 |
| --- | --- |
| 段落处理 `16/27` | 已处理 16 个段落，共统计到 27 个；处理范围包含不需要翻译的段落 |
| 新增译文 `12` 段 | 本次通过翻译调用得到的新译文数量 |
| 缓存 `1` 段 | 复用已有译文的调用次数 |
| 并行 `2` 批 | 当前正在执行的翻译批次数；显示 0 时不一定表示任务已结束 |

段落处理、翻译调用和缓存的计数口径不同，不能直接相加。初始化或排版期间日志暂时没有变化，也不能仅凭这一点判断任务失败。

日志可以滚动查看，点击 **放大日志**可收起上方设置区；再次点击 **返回设置**恢复。**查看本次日志**用于打开日志文件，**打开输出文件夹**用于定位结果。

出现“翻译完成”并显示 PDF 保存路径后，再打开结果检查。仅看到“段落处理已达到总数”不代表 PDF 已生成，后面还可能需要排版。

## 6. 停止与继续

1. 点击 **停止**并确认，等待状态变为“已停止”。
2. 原“停止”按钮变为 **继续**，已经完成的译文缓存保留。
3. 点击 **继续**恢复该任务；需要更换模型或思考强度时，在继续前选择。

继续时沿用上一任务的论文、页码、行号清理、保存位置和输出版本，并重新解析和排版；保持同一模型与强度时，会复用匹配的缓存，不是从已有 PDF 中直接追加内容。尚未完成的翻译批次可能需要重做。

**更换模型或思考强度会使用另一组缓存，可能重新翻译已处理内容。**如果要换论文、页码或输出版本，请设置好后点击“开始翻译”，创建新任务。

“继续”的任务状态仅在当前窗口中保存。关闭工具再打开后，需要重新选择论文与选项，点击“开始翻译”；相同配置下仍可复用已完成的缓存。

## 7. 查找生成结果

结果文件名会附加本次使用的模型名称，例如：

```text
paper_中文_gpt-6.1-sol.pdf
paper_中英对照_gpt-6.1-sol.pdf
```

任务文件夹中还会保留日志与任务记录。遇到失败时，可以查看 `translation.log`；需要核对任务状态、模型和结果路径时，可以查看 `manifest.json`。其中 `status` 为 `completed` 才表示任务完成。

只选择中英对照版时，结果文件夹仅交付对照 PDF，中文排版中间文件保存在本机临时目录中。

## 8. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 提示没有合适的 Python | 安装 Python 3.11 或 3.12 完整版，包含 Tcl/Tk 和 Python Launcher，然后重试 |
| 找不到 Codex CLI | 安装 Node.js LTS 后重新运行“安装依赖.cmd”，或安装官方 Codex CLI |
| 安装或首次翻译下载失败 | 查看日志中的下载错误，检查网络、代理和证书，然后重试 |
| 关闭授权网页后按钮仍不能操作 | 点击“取消登录”，或等待 5 分钟超时 |
| 登录网页出现 403，重试后正常 | 可先点击网页上的“重试”；反复出现时检查网络及浏览器拦截设置 |
| 模型列表为空或刷新失败 | 完成 ChatGPT 登录，检查网络，再点击“刷新模型” |
| 登录失效或额度不足 | 登录失效时重新授权；额度不足时等待额度恢复，重新登录不会增加额度 |
| 界面无法打开 | 在项目目录的 PowerShell 中运行 `.\.venv\Scripts\python.exe -B project.py gui` 查看具体错误 |
| 更新依赖后缓存隔离检查失败 | 重新运行“安装依赖.cmd”，使用项目固定版本依赖 |
| 翻译失败或结果不完整 | 查看“本次日志”，确认任务状态；完成后抽查公式、数值、引用和代表页 |

还无法定位时，先运行 **`检查环境.cmd`**。提供错误日志时，请隐去登录授权链接、账号信息和凭据。

## 9. 本机数据

以下位置均相对于项目文件夹：

| 位置 | 内容 |
| --- | --- |
| `.venv/` | Python 虚拟环境与翻译依赖 |
| `.runtime/tools/` | 安装脚本下载的 Codex CLI；已有可用 CLI 时可能直接使用现有安装 |
| `.runtime/codex-home/` | 本工具的 ChatGPT 登录信息与模型配置 |
| `.runtime/config/gui-settings.json` | 界面选项及上次选择文献的文件夹 |
| `.runtime/cache/` | 译文及依赖等缓存 |
| `.runtime/tmp/` | PDF 副本和排版中间文件 |
| `outputs/` | 默认结果保存位置 |

本工具不自动导入其他应用的账号。登录成功后会在 `.runtime/codex-home/account-history/` 保留旧登录的本地备份。分享项目时不要发送 `.runtime/`，其中可能包含账号凭据和论文数据。

## 10. 可选的命令行操作

以下命令在项目根目录的 PowerShell 中运行，图形界面用户可以跳过。

指定已安装的 Python 来安装依赖：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -PythonExe "C:\Python312\python.exe"
```

直接翻译原 PDF 的前三页，生成中英对照版本：

```powershell
.\.venv\Scripts\python.exe -B project.py translate "C:\papers\paper.pdf" --pages "1-3" --output-mode bilingual
```

`--output-mode chinese` 生成纯中文，`both` 生成两种版本；加上 `--remove-line-numbers` 启用行号清理，`--output-dir "C:\translations"` 指定保存位置。

无浏览器环境的设备码登录：

```powershell
.\.venv\Scripts\python.exe -B project.py login --device-auth
```

设备码方式需要账号允许使用；按终端提示在有浏览器的设备上完成授权。
