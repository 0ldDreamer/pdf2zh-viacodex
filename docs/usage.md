# 使用说明

## 首次运行

`setup.cmd` 创建专用 `.venv` 并安装固定版本依赖，配置本项目的缓存路径。已有官方 Codex 可直接使用；否则需要 Node.js，脚本将官方 CLI 安装到 `.runtime/tools`。

界面“登录 ChatGPT”按钮调用 `登录ChatGPT.cmd` → `login.cmd`，脚本的状态、登录地址及错误实时显示在界面日志中；无需在终端按键。每次运行都在临时登录目录中启动新的官方浏览器授权，不提前退出当前账号。授权成功且登录信息检查通过后，先将原凭据备份到 `.runtime/codex-home/account-history/<唯一目录>/auth.json`，再切换为本次授权的账号；取消或失败则原账号不变。备份仅留在本机私有运行目录，请勿分享。界面授权期间暂停启动或继续翻译，切换成功后重新获取模型列表。需要远程或无浏览器环境时可运行 `.venv/Scripts/python.exe project.py login --device-auth`。设备登录须账号允许。

## 模型与思考强度

启动界面自动请求官方列表；“刷新模型”会触发服务端目录更新。思考强度候选项逐模型联动，保留官方返回顺序；不支持的旧强度切换到该模型的官方默认值。全新安装采用官方默认模型，不把某个模型名称写入固定列表。

查询失败时保留最近获取的官方目录，并显示缓存提示；没有官方缓存时不能选择模型开始翻译。列表查询不会调用翻译模型推理。模型设置在“开始翻译”或“继续”时写入 `.runtime/codex-home/config.toml`。

## 保存与停止

选定保存位置后，每次新建时间戳任务目录。纯中文文件后缀 `_中文_<本次模型名称>.pdf`；对照文件后缀 `_中英对照_<本次模型名称>.pdf`。例如：`论文名_中英对照_gpt-6.1-sol.pdf`。模型名称取自本次任务固定的翻译配置，与任务记录中的模型一致。原文和译文按源页号配对，原文件的 SHA-256 校验必须不变才能交付。

停止会终止本任务的进程树，已完成并验证的段落缓存保留。停止后同一按钮变为“继续”。重新解析和排版仍需要时间；模型/强度变化会使用另一组缓存。

## 故障排查

- 缺少 Python：安装 3.11 / 3.12 完整版，并包含 Tcl/Tk。
- 缺少 Codex：安装 Node.js LTS，再运行 setup.cmd；或安装官方 Codex 后加入 PATH。`PDF2ZH_CODEX_EXE` 可指向自己的官方可执行文件。
- 登录无效或超额：重新登录或等待额度恢复；不配置 API Key 作为备用。
- 下载失败：检查代理、证书和网络。不要将不明凭据填进镜像地址或提交到源码。
- 缓存隔离检查失败：依赖升级覆盖了路径适配，重新运行 setup.cmd。只支持 requirements.txt 中锁定的版本。
- GUI 无法启动：运行 `.venv/Scripts/python.exe project.py gui` 查看终端错误。
- 译文不完整：看 `manifest.json`、`translation.log` 与 `batch-failed.json`。status 不是 completed 的任务不能作为完成结果。

首次版面模型与字体下载可能较慢，和 Codex 翻译耗时应分别看待。
